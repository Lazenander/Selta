# Cross-model law cases

`semantic-replaceability-cross-model.json` is an arbiter-side derived case,
not an implementer input. It contains one whole-`ConformanceProjection`
equality for every final `assess` case whose oracle kind is `returned`, ordered
by case ID. Admission, finite, comparison, and trap cases are excluded.

Its final assertion requires the two `presence-neither` package JCS values to
differ. That package contains truthful execution implementation identities, so
the assertion is valid only after the prediction protocol has proved that the
two sealed executable identities differ. Projection equality and full-package
inequality together state semantic replaceability without erasing provenance.

The current derived inventory has 143 assessment equalities and one package
inequality. Adding, removing, or reclassifying an assessment case invalidates
this record and requires mechanical regeneration before manifest freeze.
