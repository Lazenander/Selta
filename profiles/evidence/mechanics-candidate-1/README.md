# Mechanics candidate-1 schema sources

> **Status: schemas only; no admitted environment or conformance fixtures.**

The nine closed Selta schema sources in `schemas/` are the exact additional
contract shapes specified by
[22-mechanics-conformance-profile.md](../../../docs/22-mechanics-conformance-profile.md).
Document 22 is authoritative for their relations, call domains, resources,
errors, and dependency behavior.

The future mechanics environment will reuse candidate core and presence
contracts by exact content identity. This directory does not copy those schema
sources, compute contract or environment identities, register implementations,
or expose an application policy. Until the environment and complete corpus are
separately generated and reviewed, these files establish shape compatibility
only.
